# 🩸 Blood Donation App

A Flutter-based Blood Donation Application designed to provide a simple and user-friendly interface for blood donation services.

## 📱 About the Project

Blood Donation App is a mobile application developed using Flutter and Dart. It provides users with a simple interface to navigate between registration and login screens.

The goal of this project is to create a platform that can help connect blood donors with people who need blood.

## ✨ Features

- Welcome and Selection Screen
- User Registration Screen
- User Login Screen
- Form Validation
- Email Validation
- Password Validation
- Password Visibility Protection
- Navigation Between Screens
- Custom App Launcher Icon
- User-Friendly Interface

## 🛠️ Technologies Used

- **Flutter** – Mobile App Development
- **Dart** – Programming Language
- **Material Design** – User Interface
- **Android Studio** – Development Environment
- **Git & GitHub** – Version Control

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Malik-Muhammad-Umair/Blood_Donation_App.git
```

### 2. Open Project Folder

```bash
cd Blood_Donation_App
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Application

```bash
flutter run
```

## 📦 Build APK

To generate the release APK, run:

```bash
flutter build apk --release
```

APK location:

```text
build/app/outputs/flutter-apk/app-release.apk
```
